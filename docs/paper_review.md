This document maps the repository to the manuscript **“Dual-layer face authentication against spoofing and deepfakes using palmprint watermarking and Siamese verification.”**

## Consistency corrections recommended for the manuscript

1. **Backbone naming.** The implementation uses InceptionResNetV1 initialized from VGGFace2. The remaining ResNet-50 wording in the introduction should be replaced.
2. **Framework naming.** The supplied training code is implemented in PyTorch with `facenet-pytorch`; TensorFlow should not be listed unless a separate TensorFlow implementation is retained and released.
3. **Similarity convention.** Authentication uses cosine similarity and the rule `s_s >= theta_s`. The decision-level fusion section should not switch to Euclidean distance unless both are explicitly evaluated.
4. **Semi-hard mining claim.** The archival notebook constructs triplets before batching and applies a standard cosine triplet loss. It does not perform true online semi-hard mining. This repository provides a separate batch semi-hard implementation, but the paper should claim it only when that option is actually used in the reported experiment.
5. **Data splitting.** Random triplet-level splitting may place the same identity in training and validation. The refactored project uses an identity-disjoint split to reduce leakage.
6. **Watermark formulation.** The manuscript describes additive singular-value modulation in 8 x 8 blocks, while stronger experimental code used pairwise singular-value ordering, 4 x 4 blocks, and repeated embedding. The exact method used for each reported table must be stated explicitly.
7. **Manipulation terminology.** Bilateral smoothing, color modification, and mild affine warping constitute a controlled synthetic manipulation, not a deepfake generated by a trained synthesis model.
8. **Expected versus measured values.** Proposed NCC and BER values must not be described as measured results. The repository exports those fields only when the original 128-bit watermark and exact embedding key are supplied.
9. **Fusion claims.** A zero false-acceptance rate or guaranteed rejection of all tampering cannot be inferred from one target and one donor. The facial-manipulation study should be presented as a controlled proof of concept.
10. **Threshold provenance.** The Siamese threshold must be calibrated on a held-out validation set and stored with the experiment. It must not be selected after inspecting attack outcomes.

## Reproduction boundaries

The repository is designed to reproduce the method, not to hard-code the manuscript tables. Exact numerical reproduction requires:

- the same authorized face and palmprint images;
- the same identity-disjoint dataset split;
- the trained `face_verification_model.pth` checkpoint;
- the validation-derived Siamese threshold;
- each original 128-bit watermark vector;
- the exact extraction key generated during embedding;
- the same attack parameters and random seeds;
- the same software environment.

When any of these artifacts is absent, the output metadata records the reduced evaluation scope rather than substituting expected values.
