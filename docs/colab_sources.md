# Colab source status

Earlier project versions listed only Google Colab links, several of which
required account access. This update is grounded in the actual uploaded notebook
files. Output-stripped copies are stored under `notebooks/colab/`, and their
original SHA-256 hashes are recorded in `notebook_provenance.json`.

The repository no longer depends on private Colab links for code review or
reproduction. Users may still open the categorized notebooks in Colab after
updating data and Google Drive paths.
